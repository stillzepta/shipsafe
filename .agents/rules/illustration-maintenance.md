# Mandatory Rule: Ian Bablu Architectural Illustration Maintenance

## Mandatory Instruction
Every time new code is pushed, refactored, or any component is updated in this repository, **you MUST update the Ian Bablu architectural illustration and README description** to reflect the new system architecture, updated rules, and technical capabilities with precise detailing.

### Requirements:
1. **Consistency with Codebase**: The illustration in `assets/shipsafe-architecture.svg` and `README.md` must accurately depict the current state of the engine, modules, git hooks, SQLite audit log, and web dashboard.
2. **Strict Style Compliance**: Adhere strictly to the Ian Bablu style DNA:
   - 16:9 widescreen canvas.
   - Pure `#FFFFFF` background with generous negative space (40%–60%).
   - Crisp black ink hand-drawn lines with subtle organic jitter.
   - Bablu actively performing the core guardian task (inspecting files, rejecting leaks, stamping clean builds).
   - Sparse functional accents: Red (`#EF4444`) for blocks/quarantine, Orange (`#F97316`) for warnings/gears, Blue (`#3B82F6`) for clean paths/GitHub.
   - Concise handwritten English annotations.
3. **Commit & Push Requirement**: Never complete a feature, bugfix, or update without verifying that the architectural illustration and documentation match the live system.
